## Hero interaction
The intended hero experience:
1. Page loads.
2. Drew Roberts typography appears quietly.
3. Coin drops into the hero using Matter.js physics.
4. Coin settles.
5. Cursor approaching the coin causes a subtle reaction.
6. User can grab it.
7. Dragging follows physical motion rather than teleporting.
8. Releasing preserves throw velocity.
9. Coin collides with invisible viewport boundaries.
10. Coin rotates using real angular velocity.
11. Strong rotation can trigger a 2D front/back flip.
12. Shadow responds to motion.
13. Highlight follows the coin.
14. Interaction copy changes:
   - initial: `DRAG THE COIN`
   - after grab: `THROW IT.`
   - after successful throw: `BUILD SOMETHING.`

The hero should feel like discovering a physical object inside a portfolio, not playing a game.

Inner pages use only light Matter.js accents (1–3 bodies), never a second physics playground.
